# TAONIQ 算法系统总结

**版本：v0.10 产品适配；动力方程与映射基础：Langford v0.9。**

TAONIQ 把四柱与时间层的传统符号结构，编译成一个三维非线性系统的参数，用真实数值积分展示生辰核与流盘。其目标是让人观察“同一生辰，受到不同时间输入后，形态如何变化”。这是一套可复现的文化符号可视化实验；没有从混沌理论推导出八字学说，也没有验证个人命运预测能力。

## 1. 三个层次，各自负责什么

| 层次 | 内容与来源 | 能支持的结论 |
|---|---|---|
| 传统符号与历法 | 四柱次序、天干阴阳五行、地支五行与藏干、相生相克、合冲；依出生月柱及顺逆排大运，依节气规则计算起运 | 确定输入符号及关系，具体实现须声明流派和时间口径 |
| 动力系统数学 | 显式三维常微分方程、数值积分、平衡点与周期筛查、参数响应比较 | 说明这套人工系统在指定参数、初态与窗口下的行为 |
| 本项目设计 | 符号的数值编码、33 个原型、八参数微扰、五层预算、候选通道、校准门槛、显示投影 | 给出可检查的映射约定；这些数值不是古籍公式，也不是自然定律 |

传统资料限定于项目指定的“道家八字资料”及已核查来源。现代混沌研究用于数学方法，不用来替传统断语背书。界面的青金、朱砂、符箓式布局属于视觉语言；没有引入额外的命理规则。

## 2. 从输入生辰到生辰核

公历日期与时间首先经历法模块得到有序的 **年、月、日、时** 四柱。当前按固定 UTC+08 时钟输入，不校正出生地经度、真太阳时或历史夏令时。排运性别设定用于传统顺逆规则，并不是系统对个人身份的判断。年、月采用精确节气口径，日柱采用 EightChar sect 1（子初 23:00 换日），起运采用 getYun(gender, 2) 的分钟口径；未起运大运层为零。输入范围为 1901-01-01 至当前时刻。

出生映射保留 v0.3 的结构：每柱天干、地支、藏干分别编成圆周上的二维向量，再按 `0.5 / 0.375 / 0.125` 混合，得到每柱两个特征、共八个基础特征。藏干向量使用固定成员表的平均值，**不是“藏干力量等权”的命理断言**。进一步组合四柱位置、可见五行数、藏干展开量、跨柱差与邻柱相互作用，选择最近的结构原型。

```text
p_birth = 原型八参数 + 原型半宽 × 0.25 × (2f − 1)
```

因此同五行总量、四柱位置或干支不同的输入，有可能得到不同参数；该有限维映射不保证一一对应，更不保证肉眼形态都不同。原型数和局部范围继承既有形态探索。

v0.10 面向通用生辰：若最近原型违反旧驱动的 κ 定义域，按结构距离选择最近的有效原型，并在结果标记“工程域修复”。此项会改变原 v0.3 映射结果，所以不能称为原版本逐位复现；也不是八字纠错。没有有效原型时应明确失败，不暗中改生辰。

**“生辰核”在当前实现中指一组固定参数及其轨迹。所有生辰的数值初态统一为 `(0.1, 0, 0)`；并不是把出生时间直接当成动力系统初始坐标。**

## 3. 八参数方程

令 `r² = x² + y²`、`ω = δ + ζz + ηx`，参数顺序为 `α, β, τ, δ, ε, ζ, κ, η`：

```text
x′ = (z − β)x − ωy + κyz
 y′ = ωx + (z − β)y + κxz
 z′ = τ + αz − z³/3 − (x² + y²)(1 + εz) − 2κxy
```

这里是项目采用的 Langford 扩展形式；不能把八个参数逐个称为八个字的物理等价物。它们共同控制径向增长、旋转、剪切、耦合和耗散。圆环、折叠曲面与点都可以是真实方程输出，画出复杂形态并不自动证明存在混沌吸引子。

令 `V = (x² + y² + z²)/2`，直接求导：

```text
V′ = −βr² + τz + αz² − z⁴/3 − εr²z²
```

在 `β > 0、ε ≥ 0` 且参数固定的条件下，四次项和径向阻尼可给出有界吸收区域。旋转和耦合项在这条能量式里相消，提供优先尝试角向通道的设计动机。但它们依然改变稳定性、周期窗口和吸引域；有界不等于复杂，耗散不等于混沌。连续方程的有界性也不替代数值步长检查。

## 4. 大运与四层流时怎样进入系统

选定一个现实日期，历法模块生成当时的大运、流年、流月、流日和流时。大运来自个人出生月柱、顺逆与起运时刻；不是把年份简单除以十。起运前大运层为零，预算不会挪给其他层。

每一层干支与出生四柱逐柱比较，编码四类关系：天干生克、天干阴阳同异、地支主要五行生克、地支合冲。合冲并未穷尽刑害、三合、半合等传统关系；藏干进入出生结构，但此版时间关系通道使用地支主要五行。生克正负值、`0.75` 系数、四柱位置预算 `0.4 / 0.3 / 0.2 / 0.1`、通道混合及正交变换都是工程约定，不能解释为吉凶分值或传统力度测量。

默认时间输入预算为：

```text
大运 : 年 : 月 : 日 : 时 = 1 : 0.3 : 0.09 : 0.027 : 0.0081
```

预算只统一归一化一次。关闭某层或调整 0–2 倍强度仅改变该层，不把预算重新分配。每层关系向量单位化，再经出生时选定的固定方向矩阵 `R`：

```text
D = Σ w_s × enabled_s × multiplier_s × R u_s
Δ_j = cap_j × tanh(g A_j D_j / cap_j)    （有界候选）
```

不同通道使用不同响应与上限，避免只靠统一缩小 gain。再经正参数指数、轴根分支、β 上界及 κ 间隙变换，得到该时点的流盘八参数。沿用的轴约束不排除非轴稳定点，也不能排除圆环。非线性作用后，**大运的输入预算最大，不保证每一时点的视觉差异都最大**。

## 5. v0.9 校准，及 v0.10 的通用输入

v0.9 的关键是“**按出生固定映射方案**”。同一有序四柱和出生八参数，按共同规则选定方案；之后更改日期、实际大运、排运性别、开关或强度都不会重新选图。这样大运关闭后，其当前标签不会通过临时选路继续影响其他层。

所有新出生使用同一冻结流程：9 个候选 × 12 组固定符号探针 × 7 个控制节点 = **756 条校准轨迹**。探针不是这个人的真实经历。每个候选需满足：近定点数、全部节点简单数、默认节点简单数均不多于 v0.8；全开与去大运的平均世界密度距离和去平移/等比尺度形状距离均至少提高 5%。合格者按两项比值几何平均选最大；无合格候选就保留 v0.8，明确展示回退。

v0.10 先提供 v0.8 预览，再提供完整校准。只有真正完成这些探针与选择规则的输入才标记“已校准”；预览不得冒充 v0.9。档案缓存以出生签名和算法版本识别，未完成或取消的校准不能作为完成结果复用。新增生辰的性能与成效需要单独验证，不能继承八例旧成绩。

## 6. 时间轴究竟展示什么

当前采用**选定日期的冻结参数参照**：

```text
现实日期 t → 当时五层干支 → 参数 p(t)
每个 t：从共同初态独立积分 x′ = F(x; p(t))
```

所以时间轴或演变序列是一串“该时点输入会形成什么形态”的对照。它不是把一个人从出生至今每个流时逐步累积到当前状态，也不包含路径记忆或滞后。此前的连续历史实验与本版冻结参照须区别。

参考积分协议为 RK4，步长 `0.0025`，先运行 `600` 模型时间单位去除暂态，再记录 `90` 模型单位；每 `0.01` 保存一次，共 `9001` 个三维点。**模型时间不是现实天数**。两图用相同初态、观察协议与世界坐标投影比较。动画只是展示数值轨迹或日期采样，不是人格、事件或运势预测。

## 7. 已知证据与失败也一起保留

以下为原 v0.9 验证记录；不是所有新增 v0.10 生辰的验证成绩。精简记录和本地证据 SHA 见 [validation-baseline.json](validation-baseline.json)。

| 数据范围 | 结果 | 解读 |
|---|---|---|
| 8 个既有生辰 | 3 个选中新映射，5 个明确回退 v0.8 | 新候选没有对所有生辰达标 |
| 152 个开发条件 | 简单标记 13 → 9；近定点 0 → 0 | 用于设计的条件，不能当独立泛化证据 |
| 上述默认全开子集 56 条件 | 简单标记 3 → 4 | 总体下降掩盖了这个子集的退步 |
| 独立留出 24 条件 | 2 个旧输入域失败；22 个有效条件近周期 3 → 4，近定点 0 → 0 | 未证明普遍减少简单形态 |
| 500 图审阅批次 | 8 个生辰的 500 个生辰/日期组合；51 个近周期，449 个未标记简单；0 个近定点 | 不是 500 个独立生辰；像素不同不等于形态可辨识 |

近周期筛查检查三维状态非零时间回归，覆盖 0.1–45 模型单位并检查三个时间分段；近定点使用轨迹 RMS 阈值。有限时窗、阈值及数值误差均有限制。**“未标记简单”不等于“已证明混沌”**；若要提出混沌判断，需要另外报告相应的长期动力指标、收敛检查和适用定义。局部 Lyapunov 敏感性也不能翻译成吉凶。

曾参考用户提供的《Langford V07 图形退化诊断》，并核对其方程及锁相机制。其 800 例统计缺少对应原始数据，本项目未冒充复验；该私人附件不随公开仓库分发。

## 8. 来源与下一步

来源定位与权利说明见 [sources.md](sources.md) 和 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。Lorenz 的研究支持“确定性方程可以产生非周期、敏感的运动”这一数学事实；Milnor 的工作讨论长期吸引行为；Hunt 与 Ott 讨论混沌定义及计算判据。它们均不建立混沌与四柱之间的对应。
