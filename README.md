# TAONIQ · 太一观流

**生辰为核，时间成流。** 一个在本机运行的四柱与非线性动力学可视化实验，以青金、朱砂和仪轨式版面展示真实计算的轨迹。

输入公历生辰，查看固定的生辰核与所选日期的流盘；拖动出生至今的时间轴，单独开关大运、年、月、日、时，并调节各层强度，直接比较时间输入产生的形态变化。

## 运行

下载整个仓库，双击 `index.html` 即可。所有脚本、历法库和模型数据都在仓库内，不依赖 CDN、账号或后端；计算由浏览器内的 Worker 完成。需要支持现代 JavaScript、Canvas 和 Web Worker 的浏览器。请保留目录结构。

也可在仓库目录启动任意静态服务器，例如已有 Python 3 时：

```sh
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。这只是本地运行方法；将代码推到 GitHub 本身不代表已部署 GitHub Pages。

## 使用

1. 输入出生日期、时分秒与传统排运规则设定，生成生辰核。
2. 拖动时间轴或前后步进可准备选定日期的静态流盘。点击播放后，右侧从该图末状态连续续积分，新轨迹加入、旧轨迹退出；左侧锁定为固定生辰核。默认推进 7 天/秒，可选 1 或 30 天/秒；暂停保留当前画面与连续状态，继续播放不重新起算。
3. 分别开关五层、调节强度。默认输入预算为 **大运 ＞ 年 ＞ 月 ＞ 日 ＞ 时**；关闭一层不会把它的预算转给其他层。
4. 新生辰首先显示 **v0.8 未校准预览**。点击“校准此生辰”才执行完整 756 条探针轨迹；未达门槛会明确保留旧映射，不伪造成功。完整校准通常比单次绘图耗时更长，可停止。
5. 查看“模型与来源”，理解符号、工程映射和动力数学各自的依据。

v0.10.1 增加真实三维轨迹的透视显示：两图共用相机和尺度，默认以 6°/秒同步旋转（约 60 秒一圈），转速可调 2–12°/秒。拖动任一图或聚焦画布使用方向键可自由调整视角，并暂停自动旋转及时间播放；也可单独取消“自动旋转”。近处线条稍亮、远处稍暗，XYZ 标记指示朝向。旋转不修改轨迹或日期。系统减少动态效果、页面隐藏或已经看过的图形离屏后停止自动播放与旋转；返回后可手动开启。

所有日期按固定 **UTC+08** 输入，范围为公历 1901-01-01 至当前时刻；不处理真太阳时、经度或历史夏令时。采用 23:00 子初换日，年、月按精确节气时刻，起运用 lunar-javascript 1.7.7 的 `getYun(gender, 2)` 分钟口径；起运前大运为零。传统排运设定只用于顺逆规则。

## 这套模型在做什么

```text
有序四柱 → 结构特征 → 参数原型与局部微扰 → 固定生辰八参数
选定日期 → 大运 / 年 / 月 / 日 / 时 → 关系编码 → 参数调制
静态定位 → 同初态独立积分；播放 → 从当前状态连续续积分
固定生辰核与滚动流盘轨迹 → 同尺度、同3D相机并排观察
```

使用项目的八参数 Langford 扩展方程。v0.9 引入出生固定的候选校准；v0.10 增加通用生辰输入与输入域适配；v0.11 增加随时间驱动的连续积分及因果参数响应。八个既有案例保留出生参数精度，先前版本保留在 Git 历史中。静态校准的复杂性统计不能直接用来评价连续模式。

**这不是从混沌理论推导八字，也不是命运预测系统。** 生辰核是出生编码后的参数，初态统一为 `(0.1,0,0)`。静态定位仍采用冻结日期的独立积分；v0.11 的播放则从当前静态图末状态继续积分，保留该播放起点以后的路径记忆。它没有预先计算出生到起点之间的全部历史。最初的尾迹来自冻结图，随后逐步被连续积分的真实轨迹替换。模型时间不是公历天数；本版固定换算为每现实日 `8/7` 模型单位，改变播放速度不会改变这个比例。

## 证据与限制

v0.9 的 8 个生辰中，3 个采用新映射，5 个保留 v0.8。152 个开发条件的简单标记从 13 降至 9，但默认强度的 56 条件子集从 3 增至 4；22 个有效独立留出条件的近周期同样从 3 增至 4，另 2 个输入域失败完整保留。此前 500 图来自 **8 个生辰的 500 个日期组合**，含 51 个近周期结果。

这些记录不支持“任意生辰都复杂且独特”的保证。参数不同、像素不同、未标记简单，都不等于肉眼可辨识、已经证明混沌或命理准确。详见 [既有验证摘要](docs/validation-baseline.json)。新生辰的校准及通用输入适配需由其实际运行结果判断。

## 开发与检查

无需安装 npm 依赖；自动检查需要 Node.js 22 或更高版本。

```sh
node assets/model/build.cjs
npm test
npm run check
```

完整校准回归（每个案例实际计算 756 条轨迹）：

```sh
node tests/model-calibration.cjs T01
node tests/model-calibration.cjs T05
```

测试入口覆盖四柱映射与历法参照、时间边界、开关不变量、真实积分、Worker 与取消；T01/T05 分别覆盖新候选和校准后回退。2026-10-25 的 v0.11 检查：23 组测试及 68 项静态检查通过，其中界面逻辑包含 191 项检查和新生辰的完整校准。连续模式检查了固定生辰核、真实滚动尾迹、参数响应、跨历法边界、速度与分包不改变数值路径、暂停与导出的一致性。真实浏览器视觉及原生交互尚未验收，详见 [检查记录](docs/验收记录.md)。

校准档案默认只保存在本页内存，刷新后清除；可主动导出 JSON 保存当前生辰、时间、参考对象、参数、方案和控件状态。连续模式导出的是当前已显示帧的轨迹与状态，包含播放起点、应用参数、目标参数及固定时间换算；当前没有导入控件。
