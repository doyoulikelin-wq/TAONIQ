以象入数，
观数成形。

四柱提供有序的符号，时间带来分层的输入。我们用一组公开方程，将二者转译为可以观察、比较与复算的运动。

文化符号 × 非线性动力学

这座桥由我们设计。 混沌理论没有推导出四柱八字；本系统把传统符号编码成方程参数，用于形态实验。

轨迹复杂不代表命运复杂；形态相近不代表两个人相同。本版没有经过现实事件或个人命运的预测验证。

TRADITION / 传统结构

年、月、日、时四柱，阴阳五行、藏干、生克合冲，以及个人大运与流年、月、日、时。

DESIGN / 项目约定

为符号写编译器

由项目设计，可修改、可检验，不是古籍数值公式。

DYNAMICS / 数学模型

让方程自己成形

只描述该模型的运动，不直接解释现实人生。

生辰核是一组固定参数，不是出生初始坐标。 每柱保留天干、地支及藏干特征，按结构距离选择原型，再生成八个参数。各生辰统一从 (0.1, 0, 0) 开始积分。同五行总量仍可保留柱位差异，但不保证所有输入都形成可辨认的独特图形。

公历输入采用固定 UTC+08；不校正真太阳时、出生地经度或历史夏令时。年、月按精确节气口径，日柱采用子初 23:00 换日；起运采用历法库 sect 2 分钟口径。详见 模型契约。

03 /

八个参数，一组三维方程

令 r² = x² + y²，ω = δ + ζz + ηx。当前系统是项目采用的 Langford 扩展形式；八个参数共同作用，并不逐个等价于八个字。

x′ = (z − β)x − ωy + κyz
y′ = ωx + (z − β)y + κxz
z′ = τ + αz − z³/3
     − r²(1 + εz) − 2κxy

参数：α · β · τ · δ · ε · ζ · κ · η

旋转、剪切与耦合改变轨迹经过的位置；径向增长与耗散共同约束运动。一个稳定点、一个周期环与复杂轨迹，都可能是这组方程的真实结果。

为什么优先尝试角向通道？

令 V=(x²+y²+z²)/2，有 V′=−βr²+τz+αz²−z⁴/3−εr²z²。δ、ζ、η、κ 项在此式中相消，提供通道重分配的理论动机。它不说明这些参数对稳定性无影响；有界和耗散都不能保证复杂。

怎样判断是不是“简单圆环”？

数值筛查检查三维轨迹在非零时间延迟后是否重复，并检查三个时间分段。近周期是有限窗口提示；未被标记简单，也不能称为已证明混沌。最终仍保留原图和失败输出，供直接比较。

04 /

增强大运，不能只拧大一个旋钮

每层先与出生四柱比较生克、阴阳及合冲关系，再形成八维方向。默认输入预算为 1 : 0.3 : 0.09 : 0.027 : 0.0081，仅归一化一次。关闭一层，其他层不会获得它的预算。

D = Σ wₛ · 开关ₛ · 强度ₛ · R uₛ
Δⱼ = capⱼ · tanh(g Aⱼ Dⱼ / capⱼ)

此式适用于有界候选。v0.8 回退沿用旧映射。权重、方向矩阵与通道上限均为工程设定；非线性之后，输入预算排序不保证视觉影响排序。

  1. 先显示预览新生辰先用 v0.8 映射，明确显示尚未校准。若最近原型不满足旧输入域，选择最近有效原型并标注工程域修复。
  2. 真正计算 756 条探针轨迹9 候选 × 12 组固定符号输入 × 7 个控制节点。探针是统一校准条件，不冒充个人的真实经历。
  3. 选出生固定方案简单节点数不得增加，大运两项形态距离均须至少提高 5%；无合格候选就保留 v0.8。之后调日期或开关不会临时换方案。
05 /

两种时间，别混在一起

CALENDAR / 现实时间

用来选择输入

出生到当前的日期决定当时五层干支。大运由出生月柱、顺逆与起运时刻计算，起运前大运输入为零。

MODEL / 积分时间

用来观察运动

静态起点先去暂态 600、观察 90 模型单位。播放固定每公历日推进 8/7 模型单位，参数以 1 模型单位的响应时间趋近当时目标；这些比例是工程设定。

EVOLUTION / 演变含义

从当前状态接着算

播放不再逐图重置。流盘持续续积分，尾迹逐渐更新，生辰核固定。它累积本次播放起点以后的输入，没有预先补算出生以来的全部历史。
